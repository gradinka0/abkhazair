# Abkhaz Air

Сайт виртуальной авиакомпании в Roblox по присланному прототипу. Написан на HTML, CSS, JavaScript и Python. Конструкторов, CDN, внешних шрифтов и сервисов приёма форм нет.

## Запустить сайт с сохранением заявок

1. Полностью распакуйте новый архив в отдельную папку. Не запускайте файлы внутри ZIP. Если обновляете уже работающий сервер, замените все исходные файлы из нового архива, включая `flights.json` и папку `public`, сохраните свою папку `data` и перезапустите сервер.
2. Нужен Python 3.10 или новее. Сторонние пакеты устанавливать не требуется.
3. Windows: откройте `START-WINDOWS.bat`. macOS: откройте `START-MAC.command`. Если macOS не открывает файл, выполните в терминале из папки проекта `python3 server.py --open`. Linux: `sh start.sh`.
4. Откроется `http://localhost:8080`. Не закрывайте окно сервера, пока пользуетесь сайтом.

Можно запустить вручную:

```bash
python3 server.py --open
```

Чтобы остановить сервер, нажмите Ctrl+C в его окне. Данные сохранятся. При следующем запуске база откроется автоматически.

`localhost` доступен только на вашем компьютере. Для сбора заявок от других людей проект нужно разместить на сервере с Python и постоянным диском. Простая загрузка HTML на статический хостинг не запускает Python и не создаёт общую базу.

## Посмотреть дизайн без запуска

Откройте `abkhaz-air-v3.html` из корня архива в браузере. В этой версии видны присланный логотип, вылет 17:00 и прилёт 18:20 МСК. `preview.html` содержит ту же версию. Иллюстрация, стили и скрипты встроены в этот файл. Работают выбор языка, поиск, тарифы, пассажиры, модальные окна и FAQ.

В режиме просмотра отправка отключена: файл прямо сообщает, что заявка не отправлена. Он не подменяет серверное сохранение записью в localStorage. Для общего списка заявок используйте запущенный сервер.

## Что входит

- Чёрно-белый дизайн, плавное появление блоков, анимация иллюстрации, состояния наведения и адаптивная сетка.
- Переключатель русского, английского и абхазского. Переводятся форма, ошибки, поиск, окна, подтверждение и страница команды. Выбор сохраняется на устройстве. Абхазский текст не проходил редактуру носителем; перед публичным запуском его стоит вычитать.
- Аэропорты прибытия: Москва (Домодедово), Санкт-Петербург (Пулково), Калининград (Храброво), Брюссель. Париж и Сухум также есть в списке для деморейса и смены направления.
- Только один деморейс: Париж — Сухум, 24 ноября 2026 года, вылет 17:00 МСК, прилёт 18:20 МСК. Airbus A320-200. В пути 1 час 20 минут. Все времена указаны в UTC+3.
- Эконом — 0 Robux. Бизнес — 75 Robux за пассажира. В одной заявке 1–4 пассажира.
- Ник Roblox и ник Discord для каждого пассажира. Пароли не запрашиваются. Формат ника проверяется, существование аккаунта в Roblox или Discord не проверяется.
- Номер заявки, скачиваемое подтверждение, личный ключ доступа и раздел «Мои заявки».
- Аренда машины и отель открывают окна с сообщением, что услуга пока недоступна. Фиктивные бронирования не создаются.

Сайт принимает заявки. Он не подключён к Roblox Payments, не списывает Robux, не подтверждает оплату и не продаёт реальные авиабилеты. Для бизнеса способ оплаты нужно отдельно согласовать с командой. Сейчас любые заявки относятся к деморейсу.

## Где сохраняются все заявки

При первом запуске создаётся папка `data`:

- `requests.sqlite3` — общая база заявок. Успех показывается только после завершения записи в неё.
- `admin.key` — закрытый ключ доступа к списку всех заявок.
- `receipt.key` — внутренний ключ, необходимый для личных подтверждений пассажиров.
- SQLite может создавать рядом файлы `requests.sqlite3-wal` и `requests.sqlite3-shm` во время работы.

Нельзя удалять или публиковать папку `data`. Для переноса или резервной копии остановите сервер и скопируйте всю папку целиком. Существующие ключи нужно сохранить вместе с базой.

Заявки не удаляются автоматически. Повторное нажатие «Отправить» после сетевой задержки использует тот же ключ операции и не создаёт копию. Если после удачной отправки сознательно открыть новую форму, это будет новая заявка.

Никнеймы хранятся на сервере. В браузере сохраняются выбранный язык и ключи доступа к заявкам этого устройства. Если браузер запрещает localStorage или его очистили, открыть заявку можно по скачанному подтверждению.

## Открыть список для команды

1. Запустите сайт и перейдите в «Для команды» внизу страницы или откройте `http://localhost:8080/admin.html`.
2. Откройте локальный файл `data/admin.key` текстовым редактором.
3. Скопируйте его содержимое в поле «Ключ доступа».

В списке доступны поиск, обновление, страницы по 50 заявок и выгрузка всех заявок в CSV. Ключ не встроен в HTML и не сохраняется в браузере. Список недоступен без него.

В CSV одна строка на пассажира. Поле `Total Robux` — итог всей заявки; у группы оно повторяется в каждой строке. Для расчёта суммы берите один итог на уникальный `Request`. Сумма означает выбранную цену, а не полученную оплату.

## Размещение на своём сервере

Проект требует Python-процесс и постоянную папку для базы. Команда запуска:

```bash
python3 server.py --host 0.0.0.0 --port 8080
```

Для внешнего доступа поставьте перед ним HTTPS-прокси, сохраняющий заголовок `Host`. Папка `data` должна оставаться вне публичной папки `public`. Встроенный сервер рассчитан на небольшой проект; это не инфраструктура для большой нагрузки.

Настройки через переменные окружения:

- `ABKHAZ_DATA_DIR` — постоянная папка базы и ключей.
- `ABKHAZ_ADMIN_KEY` — свой ключ владельца, минимум 24 символа. Не помещайте его в публичные файлы.
- `ABKHAZ_PUBLIC_ORIGIN` — точный внешний origin, если прокси изменяет `Host`.
- `HOST`, `PORT` — адрес и порт.

Есть `Dockerfile`. Пример с постоянным томом:

```bash
docker build -t abkhaz-air .
docker run -d --name abkhaz-air --restart unless-stopped -p 8080:8080 -v abkhaz-air-data:/data abkhaz-air
```

Для Docker ключ находится в `/data/admin.key` внутри контейнера. После запуска задайте HTTPS на своём домене. Не отправляйте секретные ключи в общий чат.

## Следующие рейсы

Актуальное расписание сервер читает из `flights.json`. В нём сейчас только согласованный деморейс. Никаких автоматических добавлений или случайно сгенерированных рейсов нет. При добавлении настоящего рейса нужно также обновить тексты о деморежиме и статическое HTML-превью.

## Структура

- `public/index.html` — главная страница.
- `public/styles.css` — внешний вид и анимации.
- `public/translations.js` — словари трёх языков и аэропорты.
- `public/app.js` — поиск, заявка, подтверждение и личный раздел.
- `public/admin.html`, `admin.js`, `admin.css` — страница команды.
- `public/assets/airport.png` — серая иллюстрация аэропорта.
- `public/assets/abkhaz-air-logo.png` — присланный логотип, исходный файл без изменения пикселей.
- `server.py` — API, проверка данных и SQLite.
- `flights.json` — расписание.
- `preview.html` — отдельный HTML для просмотра.

## Проверки

```bash
python3 -m unittest discover -s tests -v
node tests/check_frontend.cjs
```

Node нужен только для дополнительной проверки JavaScript, не для запуска сайта.

Проверены 17 сценариев, включая запись и чтение через HTTP, сохранение после перезапуска, параллельные повторные отправки, серверный расчёт цены, закрытый доступ, экспорт и блокировку чтения служебных файлов. Проверены наличие переводов всех 131 ключа в трёх языках, ошибки, файлы и синтаксис JavaScript.

Встроенный браузерный просмотр в среде сборки был недоступен. Поэтому визуальная проверка в браузере и ручное прохождение интерфейса на телефоне не выполнены.
